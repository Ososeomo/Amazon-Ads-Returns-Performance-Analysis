## Key Analyses Performed

### 1. Search Term Analysis

- Metrics calculated: ACoS, ROAS, CTR.  
- Top Performers: Keywords like “plus size cropped jeans” had low ACoS and high ROAS.  
- Underperformers: “Black high waisted jeans” showed high spend but low conversions.  
- Recommendation: Reallocate spend toward high-performing terms and revise match types for underperformers.

### 2. Returns Analysis

- Highest return rates were found in product lines like `114_BLK_FBA` and `161_FBA`.  
- Over 75% of returns were due to sizing issues (too small or too large).  
- Recommendation: Improve sizing charts, add model sizing, and clarify listings.
